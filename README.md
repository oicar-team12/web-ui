# ShiftSync Frontend

This is the frontend part of the ShiftSync application, a tool designed to manage employee schedules, groups, and shifts efficiently. The backend is under development and will be integrated soon.

## Features

- **Dashboard**: Get an overview of your team's schedule, availability, and upcoming shifts.
- **Group Management**: Organize employees into groups, add/remove members, and manage group details.
- **Schedule Management**: (Planned) Create and manage employee schedules with ease.
- **Responsive Design**: Built with Tailwind CSS for a modern and responsive UI.

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **React Router**: For handling client-side routing.
- **TypeScript**: For type-safe JavaScript development.
- **Tailwind CSS**: For styling the application.
- **Create React App**: For bootstrapping the project.

## Getting Started

### Prerequisites

- Node.js and npm installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/oicar-team12/web-ui.git
   cd web-ui
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to `http://localhost:3000` to view the app.
